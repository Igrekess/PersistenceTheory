# Research notes

Standalone research notes and working drafts that accompany the
monograph of the Theory of Persistence (PT). None of these are
published yet; each is a self-contained piece that can be cited or
circulated as a working document. They are referenced from the
monograph (Part III map of the Riemann Hypothesis, and as
companion artifacts).

| Entry | Subject | Language | Format |

| [`pt_ramanujan_padic/`](pt_ramanujan_padic) | $p$-adic component of the qualitative PT–Ramanujan theorem. | FR | PDF + LaTeX |
| [`casimir_p29/`](casimir_p29) | Standalone note on the Casimir prediction P29 ($\Delta P/P = 1.31 \times 10^{-4}$); arXiv / CR Physique candidate. | EN + FR | PDF + LaTeX |
| [`berry_keating_cusp/`](berry_keating_cusp) | Berry–Keating operator at the cusp $\Sigma_{\mathrm{pers}}$. | FR | Markdown |
| [`apt_algebra/`](apt_algebra) | The $A_{\mathrm{PT}}$ Wick–Poisson two-branch algebra. | FR | Markdown |
| [`spectral_zeros_zeta.md`](spectral_zeros_zeta.md) | Synthesis note on the canonical spectral model of the zeros of $\zeta$. | FR | Markdown |

Each note carries its own status tags ([THM] / [DER] / [PRED] / [COND])
and should be read with the same epistemic discipline as the monograph.

The Lean 4 formalisation of the foundational theorems on the critical
path T1 → T7 → W7-1 lives in [`../pt_lean/`](../pt_lean).

## How to cite

When citing one of these notes, please also cite the Mathematics articles
bundle on Zenodo: [`10.5281/zenodo.19443954`](https://doi.org/10.5281/zenodo.19443954).
The full theory is documented in the monograph:
[`10.5281/zenodo.18726591`](https://doi.org/10.5281/zenodo.18726591). See the
[root README](../README.md#citation) for recommended BibTeX entries.
